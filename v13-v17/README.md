# V13–V17 completion batch

This directory packages the remaining major engineering stages for the railway multi-connectivity gateway.

- V13: predictive path selection combined with multi-link bonding
- V14: autonomous failover and recovery controller
- V15: passenger-aware traffic allocation
- V16: route/digital-twin future-state prediction
- V17: Linux edge gateway hardware architecture

These modules are engineering prototypes/design artifacts. They are not experimentally validated until executed and archived with raw results.
