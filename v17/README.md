# V17 — Hardware Gateway Prototype

Defines the transition from simulation to a laboratory multi-WAN edge gateway: multiple cellular/Wi-Fi interfaces, local link telemetry, packet scheduler/bonding layer, local prediction, failover controller, telemetry storage, and management interface.

## Validation target
Build a controlled lab testbed first. Measure aggregate goodput, latency, loss, failover interruption, CPU/RAM use, power, modem recovery behavior, and long-duration stability. Real railway deployment requires additional safety, regulatory, RF, carrier, and operational validation.
